# MM Repair — Android Studio Project

App name: Micro Mobile Repair
Short branding: MM Repair
Application ID: com.micromobilerepair.mmrepair
Version: 1.0 (versionCode 1)
Minimum Android: Android 6.0 / API 23
Target SDK: 35

## Open in Android Studio
1. Extract this ZIP.
2. Open the `MMRepair` folder in Android Studio.
3. Let Gradle sync/download the Android Gradle Plugin and SDK if Android Studio asks.
4. Connect an Android phone with USB debugging enabled, or use an emulator.
5. Press Run.

## Build APK
Android Studio:
Build > Generate App Bundles or APKs > Generate APKs

The debug APK will normally appear at:
app/build/outputs/apk/debug/app-debug.apk

## Build AAB
Build > Generate App Bundles or APKs > Generate Bundle(s)

The release bundle will normally appear at:
app/build/outputs/bundle/release/app-release.aab

For Google Play, create a release keystore and use Android Studio's signed build flow.
